AURA FURNITURES - React + Three.js (Vite)

1. Open this folder in a terminal (the one that contains package.json)
2. npm install
3. npm run dev      -> open the address it prints (usually http://localhost:5173)

Workshop video: set WORKSHOP_VIDEO near the top of src/App.jsx, e.g. "/workshop.mp4",
and put workshop.mp4 inside the public folder.
Build for hosting: npm run build  (output goes to dist)
